AI Agents & What They Do

The project?s analysis flow, from city data to forecasts and guidance

00

Coordinator

Plans the run, executes independent agents in parallel, skips dependants of a failed agent, and returns a trace.

01

Data Agent

Fetches Open-Meteo AQI and weather, validates freshness, ranges and completeness, and aligns timezones.

02

Weather Agent

Packages current weather and the local-day forecast with provenance (Open-Meteo model, not project ML).

03

AQI Agent

Uses the city XGBoost model when trained; otherwise the provider forecast, labelled as such.

04

Explainability Agent

Reports model feature importance (association, not causation) and rule-based meteorological context.

05

Alert/Recommendation Agent

Applies versioned AQI-category rules to current and forecast values and adds general precautions.

06

Monitoring Agent

Stores each forecast (+1/+6/+24 h) and scores it against later values: MAE, RMSE, R², persistence baseline.
